One sentence — the best advice the writer ever received, funny, plain, and quietly devastating — written to `entry.txt`.

Competition: https://make.fun/competitions/u-pangg7-the-best-advice-i-ever-got-358cefb0

## Run

```sh
npx tsx main.ts
```

The program writes a single line (1–200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validates it (one line, non-blank, no control characters), then re-reads the written file and verifies it byte-for-byte before exiting.
